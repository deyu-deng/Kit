联系 Plobi-kit

我们是一支独立的小型开发者与设计师团队。有 Bug 反馈、新工具请求,或对我们隐私优先架构的疑问?最快的联络方式是通过我们的公开 GitHub 仓库——开一个 issue,团队会尽快回复。

直接联络渠道

  • GitHub Issues(推荐): github.com/Deng-Deyu/NoCloud/issues —— 用于 Bug 反馈、功能请求与技术问题。
  • 源码仓库: github.com/Deng-Deyu/NoCloud —— 本站每一个工具的完整开源、本地运行源码。

每一个工具都 100% 在你的浏览器中运行——你在工具里输入的任何内容都不会被上传。仅有的服务端操作都由你主动触发,例如生成分享链接,或发送下面的留言表单。

关于仓库名 NoCloud

你可能会注意到,我们的代码在 GitHub 上以 NoCloud 项目名称托管。"NoCloud" 是我们"本地优先"工程哲学的代号——也正是驱动 Plobi-kit 的同一原则:你的数据留在你的设备上,而不是某人的云端。Plobi-kit 是面向公众的品牌名,NoCloud 是它赖以构建的架构。

回复时效

我们力争在几个工作日内对 GitHub issue 进行分类处理。若涉及紧急的隐私或安全问题,请在 issue 中标注,我们会优先处理。
