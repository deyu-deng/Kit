免费开发者平台与托管

这个网站自己就跑在其中的平台上，加上主流免费档的其余部分——代码托管在哪、站点发到哪、数据存在哪、演示怎么分享，全都不用信用卡。门槛是：免费档对真实项目得真的够用，而不是限时试用。其中两个我们自己在用，所以评价来自经验。

GitHub

开源和大多数私有代码的默认去处。公开与私有仓库不限量，每月有免费的 Actions CI 额度， GitHub Pages 做静态托管，还有包存储。Dependabot、代码扫描、Projects 这些生态集成，让免费版像产品本身，而不是试用版。

适合：版本控制、协作、CI/CD，以及用 Pages 免费托管静态站。

Cloudflare Pages & Workers

在 Cloudflare 的边缘网络上跑静态站点和 Serverless 函数。免费额度大得离谱：Pages 不限带宽， Workers 每天 10 万次请求，D1 数据库、KV、R2 存储都免费。这个网站就跑在这套东西上，评价来自日常使用，不是看文档写的。

适合：在边缘网络上免费上线快站点和完整应用。

Vercel

最顺的前端部署体验：推到 Git，每个分支给一个预览 URL。Next.js 集成极好（它就是 Next.js 的母公司），免费 hobby 档带宽慷慨，还含 Serverless 函数。有合理使用限制，但 hobby 项目基本碰不到。

适合：零配置部署 Next.js 和现代前端应用。

Netlify

Vercel 最接近的同侪，做静态和 Jamstack 托管：基于 Git 的部署、即时回滚、分流测试，入门档还免费带表单处理。构建插件生态和慷慨的免费额度，让它成为前端项目很稳的第二个家。

适合：需要构建预览和表单处理的 Jamstack 站点。

Supabase

基于真 Postgres 的开源 Firebase 替代品：数据库、鉴权、即时 API、存储、实时订阅。免费档给两个项目、500MB 数据库——够跑一个真正的副业项目，不只是玩具。

适合：不自己管服务器，拿到真正的后端（Postgres + 鉴权）。

CodePen

社交化的前端游乐场：三个窗格写 HTML/CSS/JS，实时看结果。公开 pen 不限量，既是可分享的演示，也是现成的教学素材。社区里的 Picked Pens 也是看 CSS 能做什么的好地方。

适合：快速的前端试验和能发给别人的演示。

CodeSandbox

浏览器里的完整开发环境，不只是游乐场。真的跑 npm install，React、Vue 这些有 DevServer，容器沙箱尽量贴近本地环境。免费档覆盖公开沙箱，时长也给得够。

适合：不碰本机也能原型一个完整框架应用。

Stack Overflow

十六年的众包编程答案。大多数搜索在到别处之前就结束在这里，投票机制通常把正确答案顶到最前。提问免费，阅读不限量；真正的技巧是搜得好——把报错信息放进去，而不是你对它的情绪。

适合：从报错信息到修好，最快的一条路。

Hugging Face

机器学习界的 GitHub：几十万个开放模型、数据集和 Spaces（从仓库直接部署的免费托管演示）。免费账号就能托管模型和演示应用，是把一个 AI 实验放到线上最省事的办法。

适合：发现和托管开放 AI 模型，演示还能免费部署。

jsDelivr

给 npm 包和 GitHub 文件用的免费生产级 CDN——不用配置，不用 API key，一个 URL 就够。任何包版本都通过全球多 CDN 网络加载。把文件提交到公开 GitHub 仓库再当永久外链用，也很好使。

适合：用快速的全球 CDN 加载任意 npm 包或 GitHub 文件，永久免费。

Regex101

正则调试的参考实现：实时高亮匹配，逐个 token 解释每个符号在做什么，还有单步调试器，能看清回溯是在哪一步炸掉的。支持 PCRE、JavaScript、Python 和 Go 方言。（我们自己也做了本地正则测试器，但 Regex101 的解释引擎确实出色。）

适合：一个 token 一个 token 地看懂、调通正则。

GitLab

一体化的 DevOps 平台：仓库、CI/CD、容器镜像仓库、issue 跟踪都在一处。在代码托管里，它的免费档对私有自动化最友好——每月 400 分钟 CI 计算时长，免费计划里私有协作成员不限。

适合：想要自带 CI/CD、不接第三方的团队。
