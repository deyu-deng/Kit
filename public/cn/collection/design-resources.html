免费设计资源

设计资源是「免费」最容易被注水的地方。下面每个站点都在不收订阅费的前提下提供真实的专业价值——要么完全免费，要么开源，要么免费档自己站得住。逐条人工复核并写清。

Figma

行业标准的界面设计工具，整个跑在浏览器里。免费版给三个项目文件、个人草稿不限量，学生、刚起步的自由职业者、以及大多数一次性的设计活都够用。实时协作是原生功能，不是后来补上去的。

适合：零安装做 UI 设计和原型。

Google Fonts

一千多款开源字体，全部允许商用、不需要署名。搭配建议、在线试排、一行 CSS 引入，让它成为网页排版的第一站——本站正文用的 Inter 就来自这里。

适合：安全、好看的网页字体，永远不会让你欠谁钱。

Fontshare

印度字厂（Indian Type Foundry）的免费字体服务：Satoshi、General Sans、Clash Display 这些家族看着像付费作品，商用免费。质量明显高于一般的「免费字体站」，目录也小到可以整个看完。

适合：不长得像别人家 Google Fonts 的标题字和品牌字。

Unsplash

高分辨率摄影，按一份简单许可免费商用（不能原样转卖）。它是被策展过的，这一点把它和那些堆满关键词的免费图库区分开——搜「workspace」，出来的照片你真的会发出去。

适合：不用为授权操心的大图头和博客配图。

Lucide

开源图标库（Feather 的一个友好分支），笔触风格统一，提供 React、Vue、Svelte 和纯 SVG 包。图标以真正的组件交付，尺寸和线宽可调，在任何框架里用起来都干净。

适合：让整个产品看起来风格一致的界面图标。

LottieFiles

Lottie 动画的集散地——基于 JSON 的轻量动效，放大依然锐利，体积是 KB 而不是 MB。免费版包含上千个现成动画，还有个网页播放器可以先预览、调速度和颜色，再导出。

适合：不请动效设计师也能加上的精致微动效。

Realtime Colors

在真实的落地页上预览配色和字体搭配，而不是看一块块色卡。粘进你的色板，看整个演示站实时换色，然后导出 CSS 变量。「色卡上好看、页面上难看」这个问题，能在用户发现之前被抓住。

适合：五分钟内验证一套配色在上下文里成不成立。

Awwwards

一个评审制的画廊，收的是全网最有野心的站点。你不是在抄它们，而是在校准自己对「能做到什么」的判断：动效、排版、布局的想法，一年后会流进主流设计。浏览免费，投稿收费。

适合：抬高你上限的灵感，而不是重复你习惯的灵感。
