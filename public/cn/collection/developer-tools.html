开发者必备网站

这些是开发者会一直钉在浏览器上的工具。入选门槛只有三条：免费档必须真能用，站点必须尊重访客，而且今天打开还得是好的。下面是过了这道门槛的，排名不分先后。

MDN Web Docs

HTML、CSS 和 JavaScript 的参考手册，由 Mozilla 和 Web 平台社区共同维护。文档和现实打架的时候，先被修正的总是 MDN。每页底部那张兼容性表格，比任何一个 Stack Overflow 帖子都更能终结争论。

适合：查某个 Web API 到底怎么表现。

Can I Use

每个 Web 特性的浏览器支持表，带用户占比滑块，让你自己判断 92% 的全球支持率对你这批访客够不够。「这个 CSS 特性现在能不能上线」，最快的答案在这里，不用翻五篇博客。

适合：判断一个新特性能不能安全用在生产环境。

web.dev

Google 关于「把网站做快、做稳」的指南：Core Web Vitals 的解释、性能模式，还有比搜索结果深得多的课程。测量工具（Lighthouse）和每个指标背后的理由，写在同一个地方。

适合：用经得起时间的方法把慢站点做快。

StackBlitz

靠 WebContainers 在浏览器里跑完整的 Node.js 环境，不用服务器，随手试也不用注册。开一个 React 或 Vite 项目只要几秒——复现一份 bug 报告、分享一个能跑的示例，这是最干净的路子。

适合：开箱即用的沙箱项目，和能发给别人的 bug 复现。

Excalidraw

手绘风格的白板，让架构图变得好下手，而不是先被吓住。没什么要配置的：打开、画框画箭头、导出。场景数据留在本地，除非你自己分享链接。

适合：架构草图和快速示意，贴在 PR 描述里也不丢人。

Squoosh

Google 开源的图片压缩器。拖进图片，用可拖动的对比滑块并排比较 WebP、AVIF、MozJPEG，然后导出——全部在浏览器本地完成。这也是我们做东西的原则：文件不离开这台设备。

适合：把图片压到最小，同时不上传到任何地方。

Photopea

一个完整得有点离谱的 Photoshop 复刻，跑在浏览器标签页里，能直接打开 PSD、XCF 和 Sketch。广告支撑的免费版没有实质功能锁，图层、蒙版、滤镜全都能用。手边这台机器没装设计软件时，答案就是它。

适合：在任何一台电脑上改 PSD，不用装东西。

tldraw

无限画布，手感好得反常——吸附、平滑、选择的顺手程度，已经是别的白板在抄的基准。网页免费版很慷慨，SDK 开源，哪天想把画布嵌进自己的产品也行。

适合：重在快、不重在精确的自由头脑风暴。

Have I Been Pwned?

Troy Hunt 的泄露数据库：输入邮箱，看哪些已知的泄露事件波及过它。它还带一个在本地做哈希的密码检查（只发送 SHA-1 哈希的前五个字符，从不发送密码本身）。如果你复用的某个密码出现在这里，今天就把它全改掉。

适合：确认账号或密码是不是已经被泄露。

Privacy Guides

社区维护的隐私软件推荐：浏览器、通讯工具、VPN、邮箱服务商。它写清理由和取舍，而不只是给个排名。有人问「哪些工具真的尊重用户」，我们就指到这里。

适合：不读营销文案，挑出尊重隐私的软件。

Wayback Machine

互联网档案馆的时光机：几十亿份网页快照，往回好几十年。被删掉的文档页、改版前的旧定价、你引用过却已经消失的来源——只要它曾经公开存在，这里很可能还留着一份。

适合：找回死掉的页面，看看一个网站以前长什么样。
