打标签与推送

命令类型说明
git tag -a v1.0.0 -m "Release v1.0.0"附注（推荐）包含打标签的人、邮箱、日期和说明
git tag v1.0.0轻量只是指向当前提交的书签，没有元信息
git push origin v1.0.0推送单个把指定标签推到远端
git push origin --tags推送全部一次推所有本地标签

标签指向 Git 历史中的某个点，通常用来标记发布版本（如 v1.0.0），配合语义化版本。

常见问题

为什么优先用附注标签？
附注标签是完整的 Git 对象，带作者、时间戳和发布说明，也能签名验证，发布场景的标准做法。

能给更早的历史提交打标签吗？
可以，把 SHA 加上：git tag -a v1.0.0 -m "Release v1.0.0"。

怎么检出某个标签？
git checkout v1.0.0（detached HEAD），或 git switch -c release-1.0 v1.0.0 从标签开分支。
