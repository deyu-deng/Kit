Cron 每季度执行（每 3 个月）— Crontab 示例

0 0 1 1,4,7,10 *

在 1 月、4 月、7 月、10 月的 1 号 00:00（午夜）执行。

逐字段解释

字段值含义
分钟0第 0 分
小时0午夜（00:00）
每月几号1每月 1 号
月份1,4,7,101 月、4 月、7 月、10 月（Q1 到 Q4）
星期几*星期几都行

财务季度（Q1、Q2、Q3、Q4）分别从 1 月 1 日、4 月 1 日、7 月 1 日、10 月 1 日开始。月份列成 1,4,7,10，或写 1-12/3，都能得到这条一年四次的干净触发。

0 0 1 1,4,7,10 * /usr/local/bin/quarterly-tax-report.sh

相关调度

0 0 1 * * 每月 1 号 0 0 1 1 * 每年 1 月 1 日 0 0 * * 0 每周日

常见问题

1,4,7,10 和 1-12/3 一样吗？
一样，1-12/3 从 1 月开始每 3 个月步进（1、4、7、10）。两种写法都成立。

能改成每季度最后一天吗？
季末月份分别是 3 月（31 天）、6 月（30 天）、9 月（30 天）、12 月（31 天）。因为天数不同，更稳的做法是在下季度 1 号跑，或者由脚本判断。

cron 有 @quarterly 简写吗？
没有，POSIX cron 里不存在标准的 @quarterly，请用显式表达式。
