Git Stash — 不提交也能暂存改动

git stash

收起所有已跟踪文件的改动，工作区变干净

git stash pop

取回最近一次 stash，并从栈里删除

git stash apply

取回但保留栈里的副本

git stash list

列出所有 stash（stash@{0} 是最新的）

git stash drop stash@{1}

删除指定的一条 stash

stash 基本流程

命令作用
git stash收起所有已跟踪文件的改动，工作区变干净
git stash pop取回最近一次 stash，并从栈里删除
git stash apply取回但保留栈里的副本
git stash list列出所有 stash（stash@{0} 是最新的）
git stash drop stash@{1}删除指定的一条 stash

包含更多文件

命令作用
git stash -u连未跟踪的新文件一起收起
git stash -a连被 .gitignore 忽略的文件也一起收起
git stash show -p stash@{0}查看这条 stash 的具体改动

stash 把未提交的改动先搁到一边，工作区立刻变干净 — 适合「我得先修别的东西」。

常见问题

stash 会包含新文件吗？
默认不会，只处理已跟踪文件。加 -u 包含未跟踪文件，-a 连被忽略的也包含。

能在 A 分支 stash、B 分支 pop 吗？
可以，stash 与分支无关。在哪里 pop 都行，冲突按合并的方式解决。

用 stash 还是开分支？
几分钟到几小时用 stash；可能活过今天的改动，开真正的分支。stash 很容易忘，也容易误删。
