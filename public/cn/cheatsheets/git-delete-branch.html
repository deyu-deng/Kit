Git 删除分支 — 本地与远端

git branch -d <name>

删除 — 分支有未合并的提交时会拒绝

git branch -D <name>

强制删除 — 即使有未合并的提交（那些提交会变成不可达）

git branch -a

列出所有分支，包括本地和远端跟踪分支

本地分支

命令作用
git branch -d <name>删除 — 分支有未合并的提交时会拒绝
git branch -D <name>强制删除 — 即使有未合并的提交（那些提交会变成不可达）
git branch -a列出所有分支，包括本地和远端跟踪分支

远端分支

命令作用
git push origin --delete <name>删除远端分支
git fetch --prune清掉本地已经失效的远端跟踪引用

删分支删的是一个指针，通常不是提交 — 只有提交变成不可达之后，Git 才会真正回收。

常见问题

-d 拒绝删除，为什么？
分支里有提交没合并到任何地方。确定不要了就 -D；否则先 merge 或 rebase。

删完分支列表里还有？
本地的远端跟踪引用过期了。git fetch --prune（或 git remote prune origin）同步一下。

能删 main/master 吗？
Git 不会让你删当前所在的分支；远端一般也有保护。该删的是功能分支。
