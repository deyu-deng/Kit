Git 合并最近 N 次提交（squash）

soft reset

git reset --soft HEAD~N && git commit -m "feat: 干净的说明"

交互式 rebase

git rebase -i HEAD~N（第一条 pick，其余 squash）

合并到 main 前

git reset $(git merge-base main HEAD) && git commit

两种 squash 做法

做法命令适合
soft resetgit reset --soft HEAD~N && git commit -m "feat: 干净的说明"快速把最近 N 条压成一条
交互式 rebasegit rebase -i HEAD~N（第一条 pick，其余 squash）需要挑选、重排或改提交信息
合并到 main 前git reset $(git merge-base main HEAD) && git commit把整个功能分支压成一条

squash 把杂乱的 wip、typo、fix 提交压成一条，再合并进 main 或开 PR。

常见问题

soft reset 和 rebase -i 有什么区别？
soft reset 一步搞定、不弹提示；rebase -i 可以逐条重排、压缩或丢弃。

已推送的提交能 squash 吗？
只建议在私有功能分支上做。已推送就必须 --force-with-lease；共享分支永远不要 squash。

怎么把功能分支所有提交压成一条？
git reset $(git merge-base main HEAD) 然后再 commit。
