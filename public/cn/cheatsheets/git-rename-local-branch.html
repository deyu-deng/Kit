Git 重命名本地分支 — 安全且即时

git branch -m <new-name>

重命名当前所在的分支

git branch -m <old-name> <new-name>

不用切过去，直接重命名任意分支

git branch -M <new-name>

强制重命名 — 即使新名字已存在

重命名命令

命令作用
git branch -m <new-name>重命名当前所在的分支
git branch -m <old-name> <new-name>不用切过去，直接重命名任意分支
git branch -M <new-name>强制重命名 — 即使新名字已存在

改名之后

命令作用
git branch --show-current确认当前分支名
git push origin -u <new-name>把新名字推到远端并设 upstream
git push origin --delete <old-name>删掉远端旧名字

重命名本地分支只是改 .git/refs/heads 里的指针，安全、即时，不碰提交历史。

常见问题

重命名本地分支会影响远端吗？
不会。本地改名只改本地引用。要同步 GitHub/GitLab，推送新名字再删掉旧的远端分支。

-m 报 already exists 怎么办？
确定要覆盖已有分支就用大写的 -M。

怎么确认改成功了？
git branch --show-current 看当前分支名。
