常见问题

为什么普通 stash 没保存我的新文件？
普通 stash 只处理 Git 已经在跟踪的文件。有新文件时用 git stash -u。

什么时候用 -a 而不是 -u？
只有想把 .gitignore 里的文件（node_modules、.env）也收起来时才用 -a，通常 -u 就够。

怎么给带未跟踪文件的 stash 起名？
git stash push -u -m "wip: 新组件"。
