解决冲突流程

步骤命令说明
1. 看状态git status找出所有 both modified 的文件
2. 编辑文件手动 / IDE选内容，删掉冲突标记
3. 暂存git add <file>标记为已解决
4. 完成合并git commit用默认信息生成合并提交
需要放弃git merge --abort回到合并前

两个分支改了同一文件的同一行时就会冲突。Git 会停下来插入冲突标记，让你决定保留哪一版。

常见问题

HEAD 那一侧的标记是什么意思？
HEAD 是当前分支的代码；分隔线另一侧是被合并分支的代码。选完内容后把三行标记都删掉。

rebase 过程中怎么中止？
git rebase --abort。

能整份文件选一边吗？
可以：git checkout --ours 保留当前分支，--theirs 用对方分支。
