Tool Documentation & Usage Guide

二维码（Quick Response Code）是一种矩阵式的条形码。它使用特定的二维几何图形记录数据符号，被广泛应用于网址跳转、数字支付和应用分发。

高效二维码生成要点：

  • 尽量精简网址: 输入的字符越少，二维码生成的黑白矩阵越稀疏，手机相机的识别与对焦速度就越快。
  • 色彩高对比度: 确保二维码的前景（通常是黑色）与背景（白色）有足够鲜明的明暗差距。

设计真正能扫的二维码

二维码只有在手机能在真实环境里读出来时才有用。最被忽视的要求是静区：每侧至少留出四个模块的空白边距。裁掉这个边距，或把码放得离其他图形太近，是本来有效的码扫不出来的头号原因。

接下来是尺寸和摆放。打印时，目标宽度至少约两厘米，让相机能分辨单个模块；在屏幕上，确保码位于远离视频或动画的平整区域。如果你在中心嵌入 logo，面积控制在 15% 以内，并依靠纠错来恢复被遮挡的数据。

务必在真实设备上测试，而不只是你的笔记本。用 iOS 和 Android 相机都扫一遍，在你用户真正会用的距离和真实场景的光照条件下测试。在显示器上很清晰的码，在海报的强烈阳光下可能发白。

常见问题解答

问：在线二维码生成器安全吗？
答：很多会把你的文本发到服务器，对专有或内部链接而言是风险。我们的工具在你的设备上 100% 本地生成，没有任何内容被上传。

问：什么是二维码的纠错功能？
答：它让二维码即使部分脏污或损坏仍可读取。共有四级，大约能恢复 7%、15%、25% 和 30% 的丢失数据。我们默认用 M 级。

问：静态二维码和动态二维码有什么区别？
答：静态码直接嵌入目标，事后无法更改；动态码指向一个短链接，你可以重新定向，但它需要服务器来解析。

问：为什么要把编码文本保持得短？
答：更短的数据产生密度更低的矩阵，手机相机扫描更快更可靠，尤其在小幅面打印时。

问：打印二维码的最小尺寸是多少？
答：打印分辨率下每个模块至少约 2 厘米宽。更高的纠错等级允许你印得更小，同时保持可扫描。

本工具的工作原理

这个QR Code Maker完全运行在你的网页浏览器内，基于 Plobi-kit 100% 客户端架构。任何输入都不会发送到外部服务器，从而保障完全的隐私与离线可用性。想验证？打开浏览器的网络（Network）面板，使用工具，然后观察：除了页面自身的资源，没有任何东西离开你的机器。
