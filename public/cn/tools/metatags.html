使用指南与 SEO 优化常识

元数据标签（Meta Tags）是书写在 HTML 头部，用以声明网页属性、核心内容和索引规则的代码标签。它不会在网页页面上直接呈现，但却会被爬虫算法和社交软件抓取分析。

社交分享图卡（Open Graph）的作用

当您在 Facebook, LinkedIn, Discord 或微信等平台发送网页链接时，系统会尝试提取 URL 中的 OG 标签并渲染出美观的大图片分享卡片，而非仅仅干瘪的文字链接，从而大幅拉高社交圈内的点击率。

爬虫收录指令说明

robots 标签用来规定搜索引擎的蜘蛛程序（如 Googlebot）是否能索引当前网页。index 代表允许爬取归档，follow 代表允许爬虫顺着网页上的其他链接继续往下抓取。

常见问题解答

问：title、description 和 OG 标签有什么区别？
答：title 和 description 驱动谷歌搜索结果摘要；Open Graph 标签控制链接在 Facebook 和 LinkedIn 上的预览卡片；Twitter 卡片控制推文中的预览。

问：title 和 description 应该多长？
答：title 控制在 50 到 60 个字符，description 在 150 到 160 个字符左右。超过这些上限，搜索引擎会用省略号截断文本。

问：什么是 Open Graph？
答：它是一套协议，用 og:title、og:image、og:url 等标签告诉社交平台如何把分享的链接渲染成富媒体卡片。

问：为什么我改了标签后预览却没有更新？
答：社交平台会激进地缓存预览。用 Facebook 分享调试器或 Twitter 卡片验证器来强制重新抓取。

问：我的输入会被上传吗？
答：不会。标签只在你的浏览器内生成，没有任何内容发送到服务器。
