使用指南与压缩原理解析

可缩放矢量图形（SVG）是一种基于 XML 格式的矢量图像标准，用于渲染支持交互和动画的二维图形。

为什么要进行 SVG 优化？

诸如 Figma、Adobe Illustrator 或 Inkscape 等矢量设计软件在导出 SVG 时，为了能够记录二次编辑信息，会强行插入大量的冗余代码。例如编辑器的命名空间、图层辅助网格、草稿注释等。这些对于浏览器渲染毫无用处但却会极大增加文件体积，清除它们能将代码瘦身 30% 到 60%。

自适应缩放模式说明

如果 SVG 代码里写死了固定 width 和 height 属性，在小屏幕手机上可能会出现显示不全或超出容器范围的情况。通过移除固定高宽，并自动根据原始尺寸生成 viewBox 属性，能让矢量图拥有自适应缩放的弹性特性。

常见问题解答

问：为什么导出的 SVG 这么大？
答：设计工具会嵌入编辑器元数据、注释、隐藏图层，以及大量对浏览器渲染毫无作用的冗余默认属性。

问：优化器到底删掉了什么？
答：它会剥离编辑器命名空间、注释、空分组和默认值，并对坐标取整。文件通常会缩小三到十倍而视觉上毫无变化。

问：压缩后的 SVG 还能编辑吗？
答：能。它仍是合法的 XML，只是人工阅读更困难。如果你之后还要改，保留一份未压缩的备份。

问：SVG 能携带脚本从而带来安全风险吗？
答：能。内联 SVG 可以携带 script 和事件处理器。我们的优化器会剥离它们，让输出在不可信环境中嵌入也安全。

问：优化时我的 SVG 会被上传吗？
答：不会。优化在你的浏览器本地运行，你的图形从不会离开设备。
