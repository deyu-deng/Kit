使用指南与常见问题

JSON 是一种用于存储和传输数据的轻量级文本格式。它经常被作为后端和前端之间传递数据的主要载体。

为什么要进行格式化和校验？

手写的 JSON 字符串经常因为少一个逗号、或者属性名称忘记用双引号包裹而导致格式错误，进而在应用程序里解析失败。我们的工具能快速指出哪一行出错了。

绝对的数据隐私保障

我们所有的格式化运算均在您的浏览器本地进行，绝对不会上传您的数据到服务器，保障您的敏感配置和密码的安全。

常见问题解答

问：为什么格式化 JSON 很重要？
答：压缩过的 JSON 对机器有效，但人几乎无法阅读。一致的缩进让你一眼就能发现缺失的逗号、未闭合的括号和错误的嵌套。

问：两空格和四空格格式化有什么区别？
答：这只是风格选择，两种都是合法 JSON。两空格在 JavaScript 和 Node 项目常见，四空格在 Python 和 Java 代码库里是传统。

问：为什么会报“Unexpected token”错误？
答：常见原因有尾随逗号、单引号、未加引号的键，以及行内注释——这些都不符合严格 JSON。如果你需要它们，应该用 JSON5 而非严格 JSON。

问：我格式化 JSON 时会把它上传吗？
答：不会。解析和校验完全在你的浏览器内进行，敏感的接口负载从不会离开你的设备。

问：怎么为生产环境压缩 JSON？
答：移除所有空白和换行来缩减体积。我们的 Minify 操作会去掉缩进，让输出尽可能紧凑以便传输。
