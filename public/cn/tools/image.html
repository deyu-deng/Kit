Tool Documentation & Usage Guide

本图片压缩器完全基于您本地浏览器中的 HTML5 Canvas API 技术。所有图片压缩与格式转换工作都在您的电脑上完成，确保您的设计资产和隐私数据绝不上传服务器。

为什么要将图片转换为 WebP 格式？

  • 极高的压缩率：在保持几乎肉眼无法分辨的画质前提下，WebP 格式生成的图片体积通常比普通的 PNG 或 JPEG 格式要小 25% ~ 35%。
  • 完美支持透明度：与 JPEG 不同，WebP 完美继承了类似 PNG 的 Alpha 透明通道特性，非常适合网页 UI 和图标素材的无缝展示。

常见问题解答

问：为什么要把图片压缩成 WebP？
答：WebP 在相同视觉质量下通常比 JPEG 小 25% 到 34%，并且像 PNG 一样支持透明通道。所有主流浏览器都支持它，因此作为 Web 默认格式很稳妥。

问：压缩会损失画质吗？
答：有损 WebP 用体积换取一些细节，照片建议用更高的质量百分比。PNG 转 WebP 除非明确选择无损模式，否则也是有损的。

问：我的图片会被上传到服务器吗？
答：不会。压缩在你的设备上端通过浏览器的 Canvas 和编码 API 完成，原文件从不会离开你的机器。

问：质量参数应该设多少？
答：75% 到 85% 是大多数网页照片的甜点区间。对视觉保真度要求高的主视觉图，可以选 90% 以上。

问：WebP 和 AVIF 相比如何？
答：AVIF 压缩效果更好，但编码更慢，对旧浏览器的支持也更参差。就广泛的兼容性而言，WebP 当下仍是务实的选择。

本工具的工作原理

这个WebP Image Compressor完全运行在你的网页浏览器内，基于 Plobi-kit 100% 客户端架构。任何输入都不会发送到外部服务器，从而保障完全的隐私与离线可用性。想验证？打开浏览器的网络（Network）面板，使用工具，然后观察：除了页面自身的资源，没有任何东西离开你的机器。
