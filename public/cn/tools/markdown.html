Markdown <-> HTML 互转

支持将原始 Markdown 语法和标准 HTML 标记相互实时转换。

使用指南与常见问题

Markdown 是一种轻量级标记语言，它允许人们使用易读易写的纯文本格式编写文档。它可以被非常方便地编译转换成 HTML 等格式进行展示。

为什么要进行 Markdown 和 HTML 的互转？

许多现代建站框架和 AI 语言模型在输出内容时都默认使用 Markdown 语法，但在实际网页上渲染时需要标准的 HTML 代码。两者的互相转换极大地方便了文案的迁移和部署。

本工具的 HTML 转 Markdown 是怎么实现的？

我们在浏览器端使用原生 JavaScript 编写了一个递归的 DOM 树遍历算法。它能够直接将常用的 HTML 标签（如标题、段落、列表、超链接、加粗、斜体、引用和代码块等）精准反向编译成对应的 Markdown 标记，不依赖体积巨大的第三方包，极大地提高了加载速度并支持离线运行。

常见问题解答

问：为什么要把 Markdown 转成 HTML？
答：Markdown 写起来快，但浏览器渲染的是 HTML。转换是把文档、笔记和 AI 输出变成可发布网页的桥梁。

问：CommonMark 和 GFM 有什么区别？
答：GitHub 风格的 Markdown 在 CommonMark 核心规范之上增加了表格、任务列表、删除线和自动链接。

问：怎么在 Markdown 里显示字面意义上的标签？
答：多数解析器会原样透传原始 HTML。要显示字面的尖括号标签，用反引号包裹它，或改用 HTML 实体编码，这样它就不会被当作标记解释。

问：转换时我的文本会被上传吗？
答：不会。解析和渲染都在本地进行，你的文档从不会离开页面。

问：能把 HTML 反过来转成 Markdown 吗？
答：可以。我们的工具支持双向。反向路径用启发式规则，对非常复杂的 HTML 可能需要轻微清理。
