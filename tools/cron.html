Tool Documentation & Usage Guide

Cron expressions are string templates representing time intervals used to schedule recurring jobs in Linux and Unix environments.

Cron Syntax Breakdown

A standard cron expression consists of 5 fields: minute, hour, day-of-month, month, and day-of-week. Special characters like * (all values), / (intervals), and - (ranges) add flexibility.

Frequently Asked Questions (FAQ)

Q: What does */5 in the minute field mean?
A: It means "every 5 minutes". It runs the job whenever the current minute value is divisible by 5 (e.g., 0, 5, 10, etc.).

Q: How do I schedule a job to run only on weekdays?
A: In the day-of-week (fifth) field, set it to 1-5 (Monday through Friday).
