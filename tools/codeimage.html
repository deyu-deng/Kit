Tool Documentation & Usage Guide

Sharing source code as plain text on social channels like Twitter, LinkedIn, or chat groups often ruins indentation and spacing rules. Converting code blocks into clean images preserves aesthetics and makes snippets highly readable.

Customization features

Choose between beautiful gradient backgrounds (Neon Sunset, Ocean Breeze) or classic solid background modes. Customize outer border margins and window file titles to fit your presentation design.

How it works offline

We load the lightweight, open-source html2canvas parser. Once you click export, the script parses the document nodes locally and converts them directly to standard base64 PNG data-url targets, triggering downloads instantly without any server round-trips.
