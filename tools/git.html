Frequently Asked Questions (FAQ)

Q: What is the difference between soft and hard reset?
A: A soft reset (git reset --soft HEAD~1) undoes the commit but keeps your file changes staged in the working directory. A hard reset (git reset --hard HEAD~1) discards the commit AND permanently deletes all changes in your files.

Q: How do I recover a deleted branch?
A: You can use git reflog to find the commit hash where the branch was, then run git checkout -b branch-name commit-hash to restore it.
