Tool Documentation & Usage Guide

URL encoding, also known as percent-encoding, is a mechanism for encoding information in a Uniform Resource Identifier (URI) under certain circumstances.

Why encode URLs?

URLs can only contain characters from the standard ASCII character set. Characters outside this set (like Emojis or Chinese characters) or characters with special syntactic meanings inside URLs (like ?, &, = ) must be encoded to prevent server parsing errors.

What is RFC 3986?

RFC 3986 is the official specification for URIs. Under standard browser JavaScript encodeURIComponent, characters like !'()* are not encoded. In RFC 3986 mode, we map those characters to their hex representations to guarantee strict compliance.
